# UK Retail CTI development instructions

The existing front-end design is replaceable. Developers may redesign, consolidate or replace the HTML, CSS, JavaScript architecture, navigation and components to improve usability, accessibility, readability, performance, maintainability or intelligence exploration. Preserve or improve useful capabilities and maintain compatibility with shared links during migrations.

## Intelligence and publication

- Preserve the Python collection pipeline, validation and traceable source attribution, AI safeguards, approved source governance, public information classification, browser-local privacy and secure publication controls.
- Publish only reviewed public intelligence. Keep source facts, attributed reporting and analyst assessment distinct. Show unknown, unavailable, incomplete, failed and stale states accurately. Use documented methods for priority and analytics.
- Keep credentials, employer information, private operational state and organisation-specific exposure or security posture out of the public site, its repository and release artifacts.
- Treat source data as untrusted. Validate links, render external text safely, and retain the Content Security Policy and the explicit publication manifest.
- Keep personal searches, watchlists, technology preferences and related browser state local. Shared links may carry deliberately selected public filters and public record identifiers.

## Front-end changes

- Target WCAG 2.2 AA. Verify keyboard operation, focus, text contrast, responsive layout, data states and both themes.
- Keep GitHub Pages project-path compatibility unless an alternative has been explicitly approved. Justify, pin and review any new dependency or build tool for security, licensing, maintainability and bundle impact.
- Use dedicated development branches for significant changes. Document architectural decisions and verify functionality, data integrity, privacy and publication against the staged site.
- Obtain explicit approval before publishing redesigns. Keep prototype fixtures outside the publication manifest.
